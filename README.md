# Алгоритм раскрашивания графа

Данная программа реализует алгоритм раскрашивания графа, основанный на поиске наибольшего независимого множества.

## Функционал

- Создание графа:
  - автоматически;
  - из файла.
- Нормализация графа (матрица смежности с 0 и 1);
- Поиск наибольшего независимого множества;
- Раскраска графа и вычисление хроматического числа;
- Сохранение матрицы и результатов в файл.

## Как использовать

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/bogdan00767/loaviz_kursovaya.git
   ```
2. Перейдите в папку проекта:
    ```bash
   cd loaviz_kursovaya
   ```
3. Скомпилируйте проект:
    ```bash
   g++ -std=c++11 main.cpp -o graph_coloring
   ```
4. Запустите программу:
    ```bash
   ./graph_coloring
   ```
5. Следуйте подсказкам в консоли для создания/загрузки графа, раскраски и сохранения результатов.
